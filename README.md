# imjin_1592 — 임진왜란 전개과정 시뮬레이션 (3학년 한국사 1차시)

history26 포털용 개별 수업 웹앱. plain HTML/CSS/JS, 빌드 없음. GitHub Pages로 배포.

- 성취기준 [9역10-04] / 기준 교과서 『중등역사②』 134~137쪽
- 구조: 도입(비교표) → 도트 지도 보드(6개 시기, 시기마다 갈 수 있는 현장이 열림. 시기 2는 두 현장 동시) → 현장 이동 → 선택 → 주사위 → 실제 역사에서는 → 같은 시기 다른 현장에선 → 엔딩(내가 지나온 길 지도, 결정적 장면) → 137쪽 영향 정리·글쓰기 → 제출
- 장면(선택지)과 결과(실제 역사 등)는 지도 위 팝업(`#pop`)으로 나온다. 900px 미만은 아래에서 올라오는 시트, 이상은 가운데 카드. 선택은 필수라 바깥 클릭·ESC로 닫히지 않고, 닫히는 건 "다음"을 눌러 지도로 돌아갈 때뿐이다. 새 쓰기 코드 없음(미리보기 영향 없음).
- 일기 쓰기 칸에는 고른 장면·선택·인물에 맞춰 바뀌는 예시 문장 틀(`data.js`의 `DIARY_FRAMES`·`DIARY_PERSONA`)과 완성 예시 한 편(`DIARY_SAMPLE`, 해당 장면을 고른 학생에게는 숨김)이 나온다. 사실 서술은 넣지 않고 쓰는 틀만 준다.
- 지도는 `map.js`(canvas 도트, 거점 버튼은 HTML overlay). 아직 안 연 거점은 안개(?)로 가려 시간순·스포일러를 막는다.
- 주사위(`data.js`의 `diceEffect`)는 가상 자원 변동 폭에만 영향을 주고 실제 역사 결과·장면 내용은 바꾸지 않는다.
- `CONFIG.GAME_NAME = 'imjin_1592'` — 커리큘럼 관리에서 이 차시 활동 id를 **같은 값**으로 등록해야 한다.
- 제출은 기본 경로(`gameName` 필수, 학생당 1행). `focus_guard.js`가 이탈·붙여넣기 신호를 함께 보낸다.
- `?sid=&name=` 자동 채움, `?preview=1` 은 저장 없이 동작한다.
- 글쓰기 입력은 앱 안에서 하고 제출 뒤 "복사하기"로 패들렛(3학년 5~8반 링크 내장)에 붙여 넣는다.

- 인물(선비·무관·백성·여인·승려): `img/avatar_<key>.png`(서 있음)와 `_walk.png`(옆모습, 이동 중). 제미나이 원본에서 배경·워터마크를 지우고 높이 64px로 줄여 팔레트를 정리한 것이다. 이미지가 없으면 `data.js`의 `AVATARS` 코드 도트로 대신한다.

- 거점 그림: 기본은 `map.js`가 코드로 그린 도트이고, `img/node_<거점키>.png`(투명 배경)를 넣고 `data.js`의 `NODE_IMAGES`에 `{ w: 너비칸수, done: 다녀온 뒤 _done.png 사용 여부 }`를 적으면 그 거점만 그 그림으로 바뀐다(키: pyeongyang, hanseong, uiryeong, jinju, dongnae, hansando, myeongnyang). 현재 한성은 경복궁 그림(w=22)이고 다녀온 뒤 불탄 모습(`node_hanseong_done.png`)으로 바뀐다.

## 핸드오프 문서 대비 바뀐 점 / 남은 일 (화면에는 나오지 않음)
- Gemini 초안의 도입 카드(조선·명 상황), 137쪽 영향 문단·역할극 대본은 사실 확인표에 없는 서술이라 쓰지 않았다.
  - 도입 비교표: 학생이 먼저 적고, 조선·일본·명 세 칸 모두 교과서 135쪽 본문 원문을 `data.js`의 `BG_TABLE[].reveal`로 확인한다. 명 칸의 발문은 135쪽 서술(명 내부 사정)에 맞춰 바꿨다.
  - 영향 비교: `data.js`의 `EFFECT_TEXTBOOK`에 교과서 137쪽 「왜란의 영향」 원문을 나라별(조선·일본·명)로 나눠 넣었다. 문장은 바꾸지 않았고, 각주 기호(➍ ➎)만 뺐다. 원문에서 일본 문단 가운데 있는 "한편, 조선에서는 투항한 일본인들이…" 문장은 조선 칸 끝에 두었다. 쪽수 표기는 `app.js`의 `showEffect()`가 붙인다.
  - 역할극: 대본은 교과서에 있으므로 앱은 137쪽을 펴 보라고만 안내한다.
- "1차/2차 원군"은 학생 화면 금지어 "2차"와 겹쳐서 "첫 번째/두 번째 원군"으로 썼다.
- 장면별 "같은 선택"으로 세는 선택지(`SCENES[].real`): 1·2·7=A, 3·4=B, 5=A 또는 C, 6=A. 6장 B·C는 학생 판단용 가정이라 정답 여부를 단정하지 않는다.
